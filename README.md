# Large Loads

An interactive guide to data centers, the grid, and the large-load rules Texas and New York are writing. Adapted from Daniel Golliher's essay in Maximum New York, ["Large Loads, Data Centers, and the Grid"](https://www.maximumnewyork.com/p/large-loads-data-centers-and-the).

Live at https://danielgolliher.github.io/large-loads/

This repository holds the built site only. It is published with GitHub Pages from the `main` branch.
